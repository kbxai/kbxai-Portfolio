# Kartik Bajaj - AI Full Stack Engineer Portfolio

Welcome to my personal portfolio repository! I am a Data Science undergraduate at IIT Madras and an AI Full Stack Engineer building intelligent, modern, and high-performance web applications.

## 🚀 Features

- **Modern Tech Stack**: Built with [Next.js](https://nextjs.org/), React, and TypeScript.
- **Immersive UI**: Custom ambient backgrounds, fluid animations, and glassmorphism effects.
- **Animations**: Powered by [Framer Motion](https://www.framer.com/motion/) for interactive UI elements and smooth transitions.
- **Responsive Design**: Fully responsive layout tailored with Tailwind CSS.
- **Clean Architecture**: Modular component structure (Hero, SkillsTrack, ProjectShowcase).

## 🛠 Built With

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React

## 💻 Getting Started

To run this project locally, follow these steps:

### 1. Clone the repository

\\\ash
git clone https://github.com/kbxai/kbxai-Portfolio.git
cd kbxai-Portfolio
\\\

### 2. Install dependencies

\\\ash
npm install
\\\

### 3. Run the development server

\\\ash
npm run dev
\\\

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
